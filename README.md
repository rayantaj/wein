# wein

وين؟ (Wein?): a daily game. Guess the Saudi city: each guess says how far and in which direction the hidden city is. Six tries, Arabic first with English, a share grid, streaks. A static site on GitHub Pages: https://rayantaj.github.io/wein/

## How to play

- Pick a Saudi city. You have 6 guesses to find the hidden one.
- Each guess shows the distance in km, the direction, and how close you are. The map shows your guesses as dots.
- A new puzzle every day. Tap `EN` / `ع` to switch language, `?` for help.

## كيف تلعب

- اختر مدينة سعودية، وعندك ٦ محاولات لتعرف المدينة المخفية.
- كل تخمين يعطيك المسافة بالكيلومتر والاتجاه ومدى القرب، والخريطة تعرض تخميناتك.
- لغز جديد كل يوم. اضغط `EN` / `ع` لتغيير اللغة، و`?` للمساعدة.
